# Automotive Service & Vehicle Analytics

A SQL and Python based academic project for managing and analysing vehicle service and maintenance data.

## Project Overview

This project demonstrates how a structured automotive service database can be used to store vehicle information, service records, maintenance activities, parts, and service costs.

The project combines **SQL database design** with **Python-based data analysis** to explore vehicle maintenance patterns and service-related information.

## Objectives

- Design a relational database for automotive service records.
- Store structured vehicle and maintenance information.
- Use SQL queries to analyse service history and costs.
- Identify basic maintenance patterns.
- Use Python for data analysis and visualisation.
- Demonstrate practical application of database and programming concepts in an automotive context.

## Main Components

- **Vehicle Management** – vehicle and model information.
- **Customer Records** – basic customer information.
- **Service Records** – maintenance and service history.
- **Parts Information** – parts used during servicing.
- **Service Costs** – tracking service-related expenses.
- **SQL Analysis** – queries for extracting useful automotive insights.
- **Python Analysis** – statistical analysis and visualisation.
