# Automotive Service & Vehicle Analytics

A SQL and Python-based academic project for managing and analysing vehicle service and maintenance data.

## Project Overview

This project demonstrates how a structured automotive service database can be used to store vehicle information, customer records, service history, maintenance activities, parts, and service costs.

The project combines **relational database design using SQL** with **Python-based data analysis and visualisation** to explore vehicle maintenance patterns and service-related expenses.

## Objectives

- Design a relational database for automotive service records.
- Store structured vehicle, customer, and maintenance information.
- Use SQL queries to analyse service history and costs.
- Identify basic maintenance patterns from service records.
- Use Python for data analysis and visualisation.
- Automate chart generation using GitHub Actions.
- Demonstrate the practical application of database and programming concepts in an automotive context.

## Main Components

- **Vehicle Management** – stores vehicle and model information.
- **Customer Records** – maintains customer information.
- **Service Records** – stores vehicle maintenance and service history.
- **Parts Information** – represents parts used during servicing.
- **Service Costs** – tracks service-related expenses.
- **SQL Analysis** – uses queries to extract useful information from automotive service data.
- **Python Analysis** – calculates service summaries and analyses costs by vehicle and service type.
- **Data Visualisation** – generates charts using Matplotlib.
- **Automated Workflow** – uses GitHub Actions to execute the analysis scripts and upload generated charts.

## Technologies

## Analysis & Visualisations

The project uses Python, pandas, and Matplotlib to analyse automotive service records and generate visual summaries of maintenance costs.

### 1. Total Service Cost by Vehicle

This analysis groups service records by vehicle and calculates the total recorded service cost for each vehicle. It helps compare maintenance expenses across vehicles.

**Output:** `vehicle_service_costs.png`

### 2. Total Service Cost by Service Type

This analysis groups service records by service type and calculates the total recorded cost for each type of service. It helps identify which service categories account for the highest recorded expenses.

**Output:** `service_type_costs.png`

### Running the Visualisation Scripts

The charts can be generated by running the following Python modules from the project root:

```bash
python -m analysis.visualize_service_costs
python -m analysis.visualize_service_type_costs
```

The scripts save the generated PNG charts in the `outputs/` directory.

## Automated Chart Generation

The project includes a GitHub Actions workflow that automates the chart-generation process.

The workflow:

1. Checks out the repository.
2. Sets up the Python environment.
3. Installs the project dependencies.
4. Initializes the SQLite database with the project SQL scripts.
5. Generates the vehicle service cost chart.
6. Generates the service type cost chart.
7. Uploads the generated PNG files as workflow artifacts.

The workflow can be triggered manually from the **Actions** tab in GitHub.

The generated charts are available as downloadable artifacts from a successful workflow run.

## Database Design

The database is designed to represent the main entities involved in an automotive service system, including:

- Customers
- Vehicles
- Service types
- Service records
- Parts
- Parts associated with service records

The SQL schema defines the database structure, while the seed-data script provides sample records for analysis.

The SQL query file contains queries for exploring vehicle service history and maintenance costs.
